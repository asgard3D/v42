# 艾諾 Online — 武道家 FBX V4

本版修正人物變形的核心問題，不再使用「單一最近頂點」轉移蒙皮權重。

## 核心修正
- 保留 FBX 原始 skin cluster 權重
- 減面後每個頂點使用 8 個最近原始頂點做反距離權重插值
- LeftShoulder / RightShoulder 不再錯誤併入 Spine2，而是併入對應上臂
- 保留 T-Pose → A-Pose 的姿勢轉換
- 不修改戰士、聖職者、盜賊的模型資料
- 本版暫不做全身白平衡／全局去飽和，避免把材質問題與骨架問題混在一起

## 目的
先確認正面、側面、背面、走路、攻擊時人物形體正常，再處理法師與武道家的最終高彩度職業配色與夜景亮度。
