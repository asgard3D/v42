# 艾諾 Online — 模組化專案（第二階段進行中）

直接用瀏覽器開啟 `index.html` 即可（使用傳統 `<script>`，`file://` 可執行，不需建置工具）。

## 目錄結構
```
index.html           只剩 DOM 骨架與 script 載入順序
css/                 base（原樣式）／devices（手機・平板・電腦）／screens（創角・離線）
js/data/             【純資料】職業與技能、外觀、裝備名稱、地圖、怪物數值 —— 無 THREE / DOM / 狀態
js/core/             util、遊戲狀態與公式（state）、存檔（save）
js/render/           Three.js：場景、主角、世界、怪物、特效、動畫（引擎相關，日後換引擎只重寫這層）
js/game/             戰鬥、技能、掉落、自動戰鬥、怪物 AI、離線收益、主迴圈
js/ui/               HUD、功能表、聊天、小地圖、面板、裝置模式
js/input/            滑鼠／觸控／鍵盤
tests/                資料層／規則層／掉落／技能樹測試（node tests/*.test.js）
```

## 角色重新染色＋細節紋理（程式生成）
- `js/render/hero-detail.js`（`HeroDetail`）：原本角色顏色來自參考圖投影的頂點色／低解析貼圖，又糊又灰又偏亮。現在**不再參考圖像顏色**：
  1. 只用原本的顏色「判斷這裡是什麼材質」（深色皮革、主色布料、金屬、白色、皮膚、眼睛），門檻很陡，讓糊掉的邊界變銳利；
  2. 每種材質改用職業指定的**實色**（暗／中／亮三段色階）重新上色，不是疊色調；
  3. 紋理的深淺直接在色階裡取色：布料斜紋＋皺褶＋下襬細褶、金屬縱向拉絲＋亮點、皮革細紋、白色亞麻紋、頭髮髮絲（亮絲取職業色）；
  4. 原圖亮度只保留一小部分當皺褶暗示，避免泛白。臉與眼睛不加紋理。
- 配色：**戰士 黑紅金**、**盜賊 黑紫金**、**聖職者 黑白藍金**（`PROF` 內改色；數值為受光前反照率，遊戲光約放大 1.2～1.5 倍，所以刻意偏深）。
- 有配色的職業（戰士、盜賊、聖職者）不再套 `hero-model.js` 的舊 `TONE` 色調，自發光改用 `PROF[k].emis`（很低，避免泛白）；其他職業不變。沒有載入 hero-detail.js 時會退回舊 `TONE` 行為。
- 調整：主控台 `HeroDetail.set(1.5)`（紋理強度，0＝只換色不加紋理，1＝預設）；各職業的主色判斷（`mainHue/mainSat/mainLum`）、金屬／眼睛飽和度門檻、皮膚是否出現在身體（`skinBody`，盜賊露指）都在 `PROF`。
- 限制：材質是從糊掉的原色「猜」出來的，圖案形狀仍受原頂點色解析度限制；要真正清晰的圖案需要 UV 貼圖。
- 測試：`node tests/hero-detail.test.js`（配色色相／亮度、整合、GLSL 括號）。
