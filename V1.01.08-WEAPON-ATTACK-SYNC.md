# V1.01.08 — Weapon / Attack Sync

Based on V1.01.07.

## Changes
- Added PlayCanvas passive Character Weapon / Attack State Sync bridge.
- Existing Three.js Character Model V2 remains visible and authoritative.
- PlayCanvas receives:
  - right/left weapon mount transforms
  - equipped weapon/offhand IDs, names and families
  - weapon/offhand visibility state
  - attack active/type/time/duration
  - movement state and speed
- No new character model is introduced.
- No PlayCanvas character is made visible in this milestone.
- Existing map, movement, EXP and skill-book behavior are preserved.

## Skill Book Behavior
Learning a skill still consumes one corresponding skill-book item from the backpack. The learned skill itself remains in the learned-skill state.
