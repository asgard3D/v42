# V1.01.42 — PlayCanvas Map Optimization

- Keeps the existing Character Model V2 and V1.01.41 Mage values unchanged.
- Adds WeakMap caching for converted PlayCanvas geometry/material resources.
- Background city mirror uses a time-budgeted frame scheduler (default 7ms/frame, up to 90 nodes/frame) instead of a small fixed batch.
- Three.js remains the authoritative gameplay/world fallback during background conversion.
- No map geometry/material content is intentionally removed.
