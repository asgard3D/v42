# V1.01.26 — High Fidelity Renderer Foundation

## Baseline
- V1.01.25 FIX-BOOT (user-confirmed stable)
- No Character Model V2 replacement
- No gameplay/map/login/character-creation reset

## This milestone
1. Renderer quality decisions stay behind `engine/render-adapter.js`.
2. Main renderer uses an Ultra profile:
   - desktop device-pixel-ratio cap: 2.0
   - mobile device-pixel-ratio cap: 1.75
   - PCF soft shadows enabled
   - continuous shadow-map updates
   - sRGB output color space
   - ACES filmic tone mapping when supported
   - exposure remains neutral at 1.0 to avoid changing existing scene brightness
3. Resize uses the same renderer-quality policy.
4. Existing boot path remains intact; Clock and DOM mounting are NOT moved.
5. This is a renderer-only foundation for the later PlayCanvas high-end pipeline.

## Intentionally not changed
- Game Core / combat / movement / EXP / drops
- Character Model V2
- maps and map loading behavior
- first-person camera behavior
- PlayCanvas bridge ownership
- manual save UI (still absent)
