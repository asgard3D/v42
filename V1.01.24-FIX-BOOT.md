# V1.01.24 Boot Fix

Fixed a regression introduced by the V1.01.23 legacy-renderer boundary migration.

- Engine Bridge had a malformed mechanical rewrite of `global.THREE` constructor expressions.
- Expressions such as `new threeLegacy...` could execute the adapter object as a constructor, stopping Runtime initialization before the boot progress reached 25%.
- All bridge Three.js lookups now use a safe `getThree()` helper, with constructors explicitly grouped as `new (getThree().Class)(...)`.
- V1.01.24 first-person camera endpoint remains 2.02 world units above the player base, with the look target raised to 2.82.
- First-person character visibility synchronization is retained.
- No gameplay, map, equipment, Character Model V2, or other camera behavior is intentionally changed.
