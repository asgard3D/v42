# V1.01.01 — Legacy Character Model V2 Weapon Attack Test

## Basis
This version continues directly from `asgard-v1.01.00(2).zip` and keeps the original Character Model V2.

## No new Base Mesh
The V1.14 new Base Mesh / custom rig is not used.

## Added
- `window.testLegacyWeaponAttack()` one-shot test
- Uses the existing Character Model V2
- Temporarily mounts the existing beginner wooden sword
- Runs the existing sword attack animation (`startAttack('slash')`)
- Restores the previous class/equipment after the visual test
- `window.testLegacyWeaponIdle()` restores a clean idle pose

## Existing game systems preserved
- Login / character slots / character creation
- Character Model V2 appearance
- Existing walk animation
- Existing combat system
- Existing equipment and weapon rules
- Existing maps and gameplay

## Test
After entering the game:

```js
testLegacyWeaponAttack()
```

Then optionally:

```js
testLegacyWeaponIdle()
```
