# V1.01.16 — Character Visual Integration

- Based on confirmed-stable V1.01.15.
- PlayCanvas weapon/offhand visuals are now enabled by default.
- The actual Character Model V2 held-weapon meshes and materials are mirrored into PlayCanvas; no replacement weapon models are generated.
- Local transforms are synchronized every frame, including attack/arm motion.
- Three.js remains authoritative for gameplay and character core logic.
- F10 is retained as an emergency fallback to restore the original Three.js weapon visuals.
