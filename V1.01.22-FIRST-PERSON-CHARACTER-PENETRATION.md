# V1.01.22 — First-Person Character Penetration

- First-person closest-point camera height raised to approximately 1.78m character-local height.
- First-person look target raised slightly for a clearer sky view.
- Added explicit `state.cameraFirstPerson` state.
- When first-person is reached, the complete Character Model V2 visual layer is hidden so the camera can pass through body, hair, face, armor, helmet, cloak, weapon and offhand without visual occlusion.
- Three.js and PlayCanvas character visibility are synchronized with the first-person state.
- Existing third-person camera, city-load optimization, auto-save and gameplay logic are unchanged.
