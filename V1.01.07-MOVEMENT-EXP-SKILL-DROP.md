# V1.01.07 — Movement / EXP / Skill Drop Fix

Based on V1.01.06.

## Changes
- WASD / Arrow movement now uses camera horizontal yaw.
  - W/Up = camera forward
  - S/Down = camera backward
  - A/Left = camera left
  - D/Right = camera right
- Camera pitch is ignored for movement direction.
- Global monster EXP multiplier is now 20× the current baseline.
- Zone-specific `expMultiplier` no longer overrides the global EXP multiplier.
- Skill-book drop chance is now 1%.
- Learning a skill consumes one skill-book item; already-learned books remain disabled as before.
- No Map / PlayCanvas / Character renderer changes.

## Safety
- Existing auto-navigation movement remains unchanged.
- Existing PlayCanvas Map and Character fallback remain unchanged.
