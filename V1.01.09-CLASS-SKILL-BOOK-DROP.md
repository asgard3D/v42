# V1.01.09 — Class Skill Book Drop

Based on V1.01.08 Weapon / Attack Sync.

## Change
- Skill book drops are now strictly limited to the player's current playable class.
- Warrior only receives Warrior skill books.
- Thief only receives Thief skill books.
- Mage only receives Mage skill books.
- Monk only receives Monk skill books.
- Priest only receives Priest skill books.
- If all skills for the current class are already learned, no skill book is generated.
- Existing 1% skill-book drop chance is unchanged.
- Existing skill-book consumption after successful learning is unchanged.

## Safety
- Invalid/non-playable class IDs cannot generate skill books.
- No change to Character Model V2, movement, map renderer, weapon sync, or attack sync.
