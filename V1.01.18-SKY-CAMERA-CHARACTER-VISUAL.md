# V1.01.18 — RPG Sky Camera + Character Visual State

Based on confirmed-good V1.01.17.

## Changes
- Reworked third-person camera around the Character Model V2 upper-body/head pivot.
- Looking upward no longer moves the visual center toward the feet.
- Camera smoothly approaches the character at high pitch, creating a close third-person / near first-person sky view.
- Camera remains above ground and behind the character; no under-character orbit.
- Added renderer-neutral Character Model V2 visual state bridge: idle / walk / windup / strike / recover.
- V1.01.17 Three.js fallback remains available.
- No gameplay, map, equipment, skill or save-data logic intentionally changed.
