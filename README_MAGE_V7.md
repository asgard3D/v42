# 法師 V7 模型修正版

本版不是單純改色。

- 使用 `T-Pose(2).fbx` 的 Mixamo 34 骨架與原始蒙皮權重。
- 與戰士／盜賊／聖職者相同：FBX → 減面 → 原始權重合併至 18 骨 → T-pose 烘成 A-pose → 內嵌模型資料。
- 修正法師原本手臂下壓 62° 過大的問題，改為 30°；因此手骨不再縮到胸口，法杖掛點也不會穿過頭部。
- 腿／腳保留 FBX 原始比例與 18 骨權重，不再用共用方塊人四肢。
- 法師配色改為實色鮮艷綠：深綠、翠綠、金色、象牙白、綠寶石、綠眼睛。
- `HeroDetail` 只負責職業實色與材質細節，不會改變骨架或模型形狀。
